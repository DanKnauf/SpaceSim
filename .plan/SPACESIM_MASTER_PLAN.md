## Notes for the big items

- **Voyagers**: propagate linearly from epoch (5× escape speed, solar
  deceleration negligible over simulation horizon). Add as destinations
  (interception = Lambert to a moving target; planner already iterates against
  moving target state). Models: build in code like the rocket (dish 3.7 m,
  3.65 m boom, RTG, magnetometer boom) — no external 3D assets allowed
  (app must stay fully local).
- **JWST**: L2 halo orbit ~1.5e6 km anti-sunward of Earth; period ~180 d.
  **Hubble**: LEO 535 km, i=28.5°, P≈95.4 min — both need size exaggeration +
  labels to be findable; both are Earth-relative bodies.
- **Comets**: pick 3-5 real comets with J2000 elements (research agent
  delivering list: Halley, Encke, 67P, Hartley 2, + one currently near
  perihelion for visible tails). Tail = billboard sprite(s) pointing anti-sun,
  opacity/length scaling with 1/r².
- **Asteroid belt**: research (agent) → rebuild `buildBelt()` with proper
  vertical (Gaussian, scale height grows with radius), radial distribution
  with Kirkwood gap depletions (2.50, 2.82, 2.95, 3.27 AU), inclination
  distribution. User perception target: flattened disk/torus with visible
  vertical extent — not a crisscross ribbon, not a sphere.
- **Gravity assists**: planner adds optional assist legs. Physics per leg:
  Lambert Earth→assist planet (or assist→dest); at flyby, hyperbolic turn
  δ = 2·asin(1/(1 + r_p·v∞²/μ_p)) around the planet's velocity vector with
  periapsis direction as free parameter; optimize flyby time + periapsis
  angle for min total ΔV / TOF to destination. Reuse `physics.js` N-body for
  verification. UI: "SLINGSHOT" section — pick assist planet(s) or AUTO.
  Trajectory line must show the bend at each flyby.
